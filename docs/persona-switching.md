# 测试阶段的人格切换

当前测试规则是每次切卡都初始化，不继承上一轮的对话、原文记忆、向量索引、人格学习或主动聊天上下文。重复选择同一张卡也会重新初始化。只打磨同一张卡的措辞，不通过切卡入口执行，就不会触发清空。

## 可选角色

| ID | 角色 | 来源 |
| --- | --- | --- |
| `dafeiyu` | 大肥鱼 v2.1 | 原有社区卡的 LonelyFriend 适配版 |
| `roast` | 毒舌损友 · 测试版 | 根据强攻击性、对线、反讽需求编写的原创测试卡 |

卡片位置和显示名称记录在 `config/personas.json`。`roast` 使用“我”和“你”或平台昵称，不沿用其他角色的“主人”“呆货”等称呼。

## Windows 后台入口

在已经配置好本项目服务器 SSH 连接的电脑上，双击项目根目录：

- `切换毒舌并初始化.vbs`
- `切换大肥鱼并初始化.vbs`

入口不会弹出终端或浏览器。执行进度和结果写入 `data/人格切换结果.txt`；切换期间聊天服务会短暂停止。名称中的“初始化”表示旧测试数据会被清空，不能将它当作普通的无损人格切换按钮。

也可以运行：

```powershell
.\.venv\Scripts\python.exe scripts/switch_remote_persona.py roast
```

## Ubuntu 入口

在服务器项目目录运行：

```bash
sudo env PYTHONPATH=/opt/lonelyfriend/extensions/python .venv/bin/python scripts/switch_server_persona.py roast
```

服务器入口先停聊天服务，再执行初始化并启动，检查插件和所选人设。切换前生成临时受限副本；启动检查失败时恢复原状态，成功后删除本次临时副本。QQ 登录进程不需要重启。

底层 `scripts/switch_persona.py` 只负责已停止服务的安装目录；发现对应 AstrBot 进程仍在运行时拒绝修改。不要在服务运行时自行改数据库或仅在管理面板选择另一张卡，这会绕过初始化入口。

## 初始化范围

清空模型会话、平台消息流水、会话名称与选择、旧主动任务、MemoryCompanion 原文及索引、学习插件状态及其备份、主动聊天上下文、链接解析媒体缓存、知识库与聊天附件、本地空间内容缓存和 RSS 推送历史。新增资讯任务会在启动时依据现有名单重建。

保留账号与令牌、QQ 登录、聊天名单、管理员权限、模型及插件配置、工具权限、静态表情与模板资源、解析器登录凭据、RSS 订阅和原有发空间计划。当天资讯投递计数也保留，避免反复切卡造成重复分享。

这里只初始化机器人本地可读取的状态，不删除 QQ 平台上已经发送的聊天或已经发布的说说。空间发文、评论、回复及私聊和群聊主动提示统一使用所选卡。

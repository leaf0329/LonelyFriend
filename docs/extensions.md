# 扩展能力

扩展沿用 AstrBot 4.29.1、NapCat 和现有角色、记忆及聊天名单，不另开一个机器人进程。上游版本、提交和本项目兼容补丁记录在 `sources.lock.json`。

## 能力与入口

| 能力 | 使用方式 |
| --- | --- |
| 聚合命令菜单 | `/菜单` 查看分类，`/菜单 全部` 查看完整列表，`/菜单 全部 2` 翻页；`/菜单 记忆`、`/菜单 表情` 等按关键词查询 |
| DeepSeek 搜索和网页提取 | 对角色说“先搜索再回答，并附来源”或提供公开网页链接 |
| 原生未来任务 | 对角色说“明天晚上八点提醒我……”；也可在 AstrBot 的未来任务页管理 |
| RSS 公开见闻 | 对角色说“看看最近有什么游戏新闻”；管理员可用 `/sub`、`/sub_list` 等管理额外订阅 |
| 热点选题 | `lonelyfriend_read_hot_topics` 读取百度、B站当前热榜，供每日分享或按需查询 |
| 万能链接解析 | 在获准 QQ 会话发支持的平台链接，或让角色调用 `parse_media_url` |
| 模板表情 | `#举牌 今天也要开心`、`#摸头`；也可让角色自然调用 `lonelyfriend_make_meme` |
| 自主学习 | 管理面板的自主学习插件页可查看群聊采集、表达、黑话、人设审查与备份 |
| Steam活动监测 | `/Steam状态` 查看指定玩家的在线、游戏及可读取的游戏内活动；配置与登录见 [Steam活动监测](steam-presence.md) |

搜索与正文提取复用本机配置的 DeepSeek API 密钥，费用由 DeepSeek 账户承担。网页需要登录、目标站阻止访问或服务超时时，不能保证正文可读；解析器也可能需要特定平台凭据。解析成功不代表模型已经看过完整视频。

命令菜单由 AstrBot 实时注册表生成，包含已启用插件及其子命令，使用当前命令名称与唤醒前缀；改名、停用和权限设置会随下一次查询生效。支持 `/命令菜单`、`/功能菜单` 两个别名。分类或关键词列表每页10项；`/菜单 完整命令名` 展示该命令登记的说明，模块帮助可进一步查看参数。菜单按当前发送者与会话权限过滤，群热点审核项仅向指定审核人的真实QQ私聊显示。部分插件还有自己的内部开关，列出命令不代表对应功能必然开启；自然语言工具也不等同于斜杠命令。系统 `/help` 仍提供内置命令帮助。

## 每日热点与 RSS 阅读

公开策略位于 `config/extensions.json`，运行时副本为 `data/extensions.json`。初始源为 IT之家、Solidot、机核和 ACG17，覆盖科技、AI、游戏和动画。

默认北京时间每天 20:17 为当前私聊名单和群聊名单各安排一次原生主动任务。定时任务先读取百度实时热搜和B站搜索热榜，只提供前20名、正热度、榜单更新时间不超过30分钟的候选。排除百度置顶条目、B站商业投放和可识别的招聘、促销、趣图、播客栏目标题；随后由角色筛选科技、AI、游戏、动画中有讨论价值的重大进展、争议或赛事结果，跳过普通产品规格、小版本更新和无新进展的旧闻。

候选保留平台、排名、热度和榜单更新时间。平台热度口径不同，不跨平台直接比较分数；单个平台上榜不代表全网第一。任务要求再通过现有 DeepSeek 公开搜索或网页提取核实关键事实，不能把热榜标题直接当作完整事实。

没有合适选题或榜单不可用时不推送，不发占位话，也不回退到普通RSS最新文章。发送工具会再次检查候选热度、时间及完整链接，旧RSS缓存不能通过这项检查。热榜快照保存在 `data/plugin_data/astrbot_plugin_lonelyfriend_activities/hot-topics.json`，最多缓存10分钟；单个榜单失败仍可使用另一来源，所有来源失败时覆盖旧候选，避免沿用过期内容。

原有 IT之家、Solidot、机核和 ACG17 仍供 `lonelyfriend_read_feeds` 按需阅读，不再直接充当每日热点候选。榜单数据直接来自[百度热搜](https://top.baidu.com/board?tab=realtime)和[B站搜索热榜](https://s.search.bilibili.com/main/hotword?limit=30)，不需要另装聚合服务、浏览器或额外 API 密钥。榜单机制参见[百度榜单规则](https://top.baidu.com/board?page=rule&tab=realtime)；上游页面或接口结构变化时可能暂时取不到候选。

每日投递只允许文字和当前获准会话，检查来源链接，23:00—08:00不发。定时任务仅开放热榜读取、公开搜索、网页提取和受限投递工具，不开放私人记忆、通用发送或新建定时任务。投递前持久化当日尝试记录，避免并行调用、重复执行或网络结果不明确时重复推送。因此一次投递失败也可能消耗当天机会；失败会保留在工具结果、日志与 `data/plugin_data/astrbot_plugin_lonelyfriend_activities/delivery.json` 中。

### 群热点的人工审核

群热点先保存草稿，私发指定审核人，经过明确通过才发送到对应群。群内关闭普通聊天和 @ 对话，但保留明确的工具命令、链接解析与工具通知；私聊自己的每日推送及低频主动聊天继续使用各自规则。

群草稿在独立定时任务上下文中生成，不继承真实群聊或审核人的私聊历史，未审正文也不写回真实群对话，避免后续聊天将草稿当作已公开内容。

审核账号放在私有 `data/news-review.json`，格式参照 `config/news-review.example.json`；该账号必须同时在管理员和私聊名单内。未配置有效审核人时禁止群热点发送，不回退到自动群发。审核命令仅接受该账号的真实QQ私聊，其他管理员、群内命令、正文里自报身份和定时任务都不能代审。

审核通知包含审核号、目标群、将原样发送的完整正文、热点来源及排名与热度、榜单更新时间和选题理由。通过后只发送这份保存的正文，不能临时换群、改写或附加未审核内容。每群每天只提交一份草稿；拒绝后当天不自动重选或反复通知。草稿有效至当天23:00，未审不发，过期失效。人工审核可能晚于选题时的榜单快照，通知保留其时间供判断。

| 私聊命令 | 用途 |
| --- | --- |
| `/热点通过 审核号 [原因]` | 批准并发送原文，可记录认可理由 |
| `/热点拒绝 审核号 [原因]` | 拒绝发送，保存拒绝理由 |
| `/热点待审` | 最近五条待审草稿 |
| `/热点查看 审核号` | 完整正文、审核意见与时间记录 |
| `/热点记录` | 最近五条记录及其当前状态 |
| `/热点审核统计` | 按来源统计通过、拒绝、已发及待审数量 |

真实通过与拒绝单独记为内容反馈；未审、过期、取消和网络失败不计作内容被拒绝。发送前先持久化批准与投递预留，结果不明确时不自动重发；重启后将未确认发送显式记为未知，重复审批也不会再发。

审核数据保存在 `data/plugin_data/astrbot_plugin_lonelyfriend_activities/news-review.db`，包含原文、目标群、热榜证据、选题理由、审核账号与意见、各阶段时间及发送结果。记录独立于聊天记忆长期保留，测试初始化后旧待审稿失效，历史记录不删除。私有迁移包包含该库的SQLite快照和审核配置；真实审核资料不提交公开GitHub。统计与理由供后续选题调整参考。

每日热点任务不由框架在启动时直接恢复执行，只有审核插件健康加载后才安排；卸载插件时暂停这几项任务。这样审核模块未加载时不会恢复原来的直接群发方式，其他提醒任务保持原有规则。

这是新增资讯分享的上限；低频私聊主动聊天和空间发布仍使用各自的配置。管理员自行创建的其他提醒任务不计入资讯分享上限。

RSS 管理命令限管理员使用。群内保留明确的工具命令与既定通知；需要角色理解的自然语言资讯请求在获准私聊中使用，不因此获得新增订阅、批量推送或全局清理的权限。

## 自主学习与人设

默认只采集开放群的消息，不把私聊内容作为全局人格的学习样本。名单更新通过 `scripts/set_access.py` 同步到解析器与学习插件；没有开放群时不会退化成全量采集。

学习默认每六小时检查一次，达到上游默认的50条消息门槛后按批次处理。黑话与表达学习、人格细节自动应用开启；额外的记忆图、知识图谱、本地机器学习分析、独立网页服务关闭。现有 MemoryCompanion 继续负责长期记忆。

人格更新前备份，备份失败则停止该次自动修改。兼容补丁让备份和恢复保留工具权限等人格字段，避免恢复后意外开放所有工具。学习仍可能产生错误理解或风格偏移，需要通过管理页观察、撤销或停用；它不是训练 DeepSeek 的模型权重。

## 安装与维护

基础安装不自动加载可选扩展。获取 `sources.lock.json` 中标为 `optional` 的上游插件后，在原有 Linux 环境旁准备附加依赖：

```bash
.venv/bin/python -m pip install --target extensions/python --no-deps -r requirements-extensions.lock.txt
```

服务通过 systemd 的环境项 `PYTHONPATH=/opt/lonelyfriend/extensions/python` 使用附加依赖，基础虚拟环境保持独立。停止聊天服务后应用设置，再启动：

```bash
PYTHONPATH=/opt/lonelyfriend/extensions/python .venv/bin/python scripts/apply_extensions.py
sudo systemctl restart lonelyfriend
```

脚本应用已固定的上游兼容补丁，只增补搜索、主动任务、扩展配置和当前角色工具，不重建聊天数据库或重置角色正文。修改角色正文、长期记忆策略或首次初始化配置时，应先备份已有的人格与配置。

表情生成使用 `meme_generator==0.2.3` 的完整图片与字体资源，放在 `data/plugin_data/astrbot_plugin_meme_generator/resources/`。离线安装的资源清单来自上游 `v0.2.3/resources/resources.json`，文件须通过作者 SHA-256 校验，清单附加 `version: "0.2.3"` 字段。补丁在已校验的资源齐全时跳过启动时的 CDN 下载扫描。资源约400 MB磁盘空间；不需要 GPU 或额外的生图 API。

解析与表情制作各串行处理，解析音视频限制为200 MB、60分钟，下载请求超时为120秒；这些限制可以在插件配置中调整。原图/GIF发送仍会消耗服务器流量。

停用扩展时先停聊天服务，移出新增插件，恢复对应配置并撤销 systemd 的附加依赖环境项，再启动服务。无需退出 QQ 登录，也不需要清空聊天数据库。

部署前的数据库快照用于切换失败时恢复。正式产生新消息后，不要直接拿旧数据库覆盖；应保留现有历史，只恢复所需的人格字段或配置。备份包含私人资料，只应放在服务端受限目录，不能上传公开仓库。

# 记忆设计

LonelyFriend 使用 MemoryCompanion 2.3.1 保存与组织记忆，项目适配器负责获准 QQ 完整文字、中文本地 Embedding、消息身份提示和已验证的接口兼容修正。继续使用已有 `dafeiyu` 人格 ID，避免切换外观人设后丢失原来的记忆归属。

## 三层信息

1. **工作对话**：当前上下文和近期完整轮次；接近预算时总结更早的上下文。
2. **长期记忆**：有出处的阶段总结、偏好、人物关系与事实；召回时结合关键词、语义、时间、有效性和权限。
3. **原文档案**：获准 QQ 来信的完整文字。摘要遗漏时，可以语义发现、搜索、读取前后文和继续补读长消息。

原文和派生索引分开保存。原文保留策略为不按天自动删除；自动归档关闭。向量、片段窗口和关系信息可以重新建立，不能替代原文作为事实依据。

## 时间衰减与使用强化

采用插件已有的指数衰减近似，`R(t) = exp(-ln(2) × t / H)`，其中 H 为记忆类型对应的半衰期。它是工程上的排序策略，尚未针对个人做心理学意义上的拟合。

| 持久度 | 半衰期 | 典型信息 |
| --- | --- | --- |
| ephemeral | 1 天 | 原始短时事件类记录 |
| short | 14 天 | 当前情绪、临时状态、日程片段 |
| normal | 120 天 | 普通经历与阶段总结 |
| durable | 730 天 | 长期偏好、人物关系、承诺等 |
| pinned | 不按时间衰减 | 明确固定保存的记忆 |

具体分类由原生记忆类型、写入参数和既有元数据决定。时间衰减影响排序；显著性和实际注入强化还会影响最终得分。原生评分对新鲜度影响设有下限，避免仅因年代久远而把相关事实降为零分。

本配置保留这一软衰减，关闭会把旧派生记录移出普通检索的自动归档。当前状态问题仍需近期依据；问到往事时则可以回查旧原文。生日、称呼等稳定信息不应与一时的“今天很累”使用相同保留方式。

## 本地混合检索

Embedding 使用 `BAAI/bge-small-zh-v1.5` 的 Qdrant ONNX 版本，固定模型修订，512 维，通过 FastEmbed 在 CPU 上运行，线程数为 `min(4, CPU 数)`。模型准备脚本下载指定文件，正常聊天时只读取本地模型。

模型输入有限长，原文按 320 字符、48 字符重叠切片；较长的向量输入进一步分片并合并表示，减少仅编码开头造成的细节遗漏。语义结果是相关候选，仍需核对原文、更正和事件归属。

对原生策略识别出的历史追问，适配器在首次回答前补入少量获准原文候选，排除本轮问句自身。复用原有可见性、工具预算和临时上下文接口，不为普通闲聊强制添加往事。索引若尚在建立，最多等待 3 秒，其余工作在后台继续。

Embedding 不额外上传聊天文字。真正被选入回复上下文的记忆片段，仍会发送给配置的 DeepSeek 服务。模型缺失时明确报告语义检索不可用，已有关键词与原文查询继续工作。

## 接口与交互修正

- MemoryCompanion 2.3.1 的语义投影边界收到 SQLite JSON 字符串时，未能识别完整采集记录，会误用 4000 字符的旧投影路径。适配器先规范元数据，保持完整采集原文的语义覆盖，并更换投影版本以便重建。
- 上游原文索引每次触发只处理有限批次。适配器在后台继续有明确进展的批次，覆盖长消息末尾和旧记录；暂停、错误和单次工作上限均明确保留状态。
- 补全现有语义发现工具的参数描述，以及请求级包装工具缺少的查询参数；不添加已被人设或权限移除的工具，也不改变底层可见性裁决。
- 缓冲工具调用中间回复，减少“我先翻翻”等文字先于查找结果单独发出。最终答复仍由模型生成。
- 输出使用本轮最终回答，避免把查找前的不确定表述与查找后的结论直接拼接；其他命令结果保留原有发送方式。
- 平台发送者身份只用于识别账号所有者，不注入全局固定称呼。称呼按当前角色卡处理，其他角色的历史或记忆不能覆盖当前卡的称呼规则；昵称、引用和正文中的自报身份不能改变账号归属。

兼容修正针对 AstrBot 4.29.1 与 MemoryCompanion 2.3.1。升级第三方组件前须重新验证这些边界。

## 已知限制

- 摘要抽取、模糊指代与模型对证据的解释仍可能有遗漏；保留原文不保证每次都能检索到。
- 多阶段回忆增加模型往返，首次建库和大量历史回填也需要 CPU、存储与时间。
- 索引与工具均有候选、字数和步骤预算，结果不是“已查全所有历史”的证明。
- 当前完整文字采集覆盖获准 QQ 来信，单条上限 256 KiB；媒体和角色回复沿用原有路径。
- 私聊与群聊隔离会限制跨窗口回忆，这是本项目的既定隐私边界。
- 本地程序在电脑关机后停止；服务器部署与平台扫码登录仍是独立的运行条件。
